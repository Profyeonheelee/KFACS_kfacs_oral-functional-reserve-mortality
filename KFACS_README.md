# KFACS Oral Functional Reserve & Mortality — Code Package

Analysis scripts for the KFACS study of oral functional reserve, functional dentition, and all-cause mortality in community-dwelling older adults. The repository contains Python and R code used to reproduce the main and supplementary analyses reported in the manuscript.

## Repository contents

### Python workflow

The Python workflow builds the analytic datasets from the KFACS source files and reproduces the main and supplementary analyses.

Run `00_setup_and_mice.py` first. Set `DATA_DIR` near the top of the script to the directory containing the required source datasets:

- `_최종_2016_2024_KFACS.xlsx`
- `_최종_2016-2020_통합자료_치과_v20230904_LYH.xlsx`
- `outcome_w1w5.xlsx`
- `KFACS_추적조사상세_최종_260608__2_.xlsx`

The setup script creates the intermediate datasets used by the remaining Python scripts, including:

- `baseline.pkl`
- `final_preMI.pkl`
- `mi_long_v2.pkl`
- `landmark_cohort.pkl`
- `physical_measures.pkl`
- dental extract `.pkl` files for baseline and follow-up assessments

Helper modules:

- `coxph.py` — Cox proportional hazards regression with Efron handling of tied event times
- `pooling.py` — Rubin-rule pooling across multiply imputed datasets

Main-analysis scripts:

- `table1_code.py` — Table 1: baseline characteristics according to functional dentition status
- `table2_code.py` — Table 2: Cox proportional hazards models for oral functional reserve and all-cause mortality
- `table3_code.py` — Table 3: sequential pathway attenuation models
- `figure1_code.py` — reproduces the data-derived cohort counts used in Figure 1B

Supplementary-analysis scripts:

- `etable1_code.py` — eTable 1: adverse systemic reserve marker components
- `etable2_code.py` — eTable 2: variable definitions, derivation rules, and data-based validation audit
- `etable3_code.py` — eTable 3: analytic cohort, variable availability, and death ascertainment
- `etable4_code.py` — eTable 4: oral exposure distributions and functional dentition reclassification
- `etable5_code.py` — eTable 5: dental follow-up change analyses and landmark Cox models, fitted across 20 imputed datasets and pooled with Rubin's rules
- `etable6_code.py` — eTable 6: sensitivity and extended Cox analyses
- `etable7_code.py` — eTable 7: exploratory baseline implant-supported reclassification analyses
- `efigure1_code.py` — eFigure 1: distribution of baseline oral functional reserve measures
- `efigure3_code.py` — eFigure 3: sequential pathway attenuation plot

`efigure3_code.py` uses `table3_output.csv`, generated by `table3_code.py`.

Figure 1A is a conceptual schematic. `figure1_code.py` reproduces the data-derived counts used in the analytic cohort workflow shown in Figure 1B.

### R scripts

The R scripts reproduce analyses that are implemented directly in R:

- `Figure 2.R` — Figure 2: Kaplan–Meier survival estimates with Greenwood 95% confidence intervals and log-rank comparisons
- `eFigure2.R` — eFigure 2: deficit-based dose-response association below the natural-teeth or functional-dentition threshold
- `etable8_code.R` — eTable 8: full incremental prognostic performance analysis, including Uno's C, 5- and 8-year time-dependent AUC, 5- and 8-year Brier scores, 5-year continuous NRI, Rubin-pooled Wald tests, and B=200 bootstrap optimism correction for the change in Uno's C

For the R analyses, place `KFACS_analytic_dataset_MICE_v2.xlsx` in the working directory or edit the data-path variable near the top of the corresponding script.

The eTable 8 script uses all 20 imputed datasets in the analytic workbook. It writes per-imputation results, pooled summaries, bootstrap validation results, and a publication-format eTable 8 output.

## Recommended run order

1. Run `00_setup_and_mice.py`.
2. Run the main and supplementary Python table scripts as needed.
3. Run `table3_code.py` before `efigure3_code.py`.
4. Run `Figure 2.R` and `eFigure2.R` using the multiply imputed analytic workbook.
5. Run `etable8_code.R` for the complete eTable 8 prognostic-performance analysis.

## Implementation notes

- The Python Cox model uses Efron handling of tied event times and Newton-Raphson optimization.
- The Python multiple-imputation workflow uses `sklearn`'s `IterativeImputer(sample_posterior=True)` with Bayesian ridge regression and generates 20 imputed analytic datasets.
- R scripts that use `KFACS_analytic_dataset_MICE_v2.xlsx` operate on the prebuilt 20-imputation analytic dataset and do not perform a separate imputation step.
- Functional dentition is defined as the sum of remaining natural teeth and implant-supported restorations, capped at 32.
- `physical_frailty_burden_no_weight_loss` is calculated from the CHS frailty component total after removing the weight-loss component.
- The adverse systemic reserve marker count includes low albumin, anemia/low hemoglobin, elevated high-sensitivity C-reactive protein, and vitamin D deficiency; it is calculated when at least 3 of the 4 components are nonmissing.
- Mortality status and follow-up time are derived from serial KFACS center, home-visit, and telephone follow-up records linked by participant ID. When multiple death records are available, the earliest usable record is retained, and incomplete death dates are handled according to the predefined derivation rules.
- Landmark analyses use repeated dental assessments and count deaths occurring after the relevant landmark time.
