# KFACS_kfacs_oral-functional-reserve-mortality
Using KFACS data, this project examines whether oral functional reserve—particularly functional dentition and natural tooth retention—is associated with all-cause mortality in older adults, and evaluates its incremental prognostic value beyond conventional risk factors.



KFACS Oral Functional Reserve & Mortality — Code Package

This repository contains analysis and figure-generation scripts for the KFACS study of oral functional reserve, functional dentition, and all-cause mortality in community-dwelling older adults. Python and R implementations are included to support reproducibility and cross-checking of selected analyses.

Implementation notes

The Python Cox proportional hazards implementation uses Efron handling of tied event times and Newton–Raphson optimization.

The Python multiple-imputation workflow uses sklearn's IterativeImputer(sample_posterior=True) with Bayesian ridge regression. Analyses based on the pre-built R MICE export may show small numerical differences because the imputation procedures are not identical.

physical_frailty_burden_no_weight_loss is calculated as chs_total - weight_loss_flag; chs_total is defined as the sum of the five Cardiovascular Health Study frailty components.

Death-ascertainment source (telephone call, center visit, or home visit) is not reported because the available per-wave response codes do not contain a specific death indicator.

Reproducibility

To reproduce the Python analyses, first run 00_setup_and_mice.py and then run the desired table or figure script using the generated intermediate datasets. For the R analyses, use the pre-built KFACS_analytic_dataset_MICE_v2.xlsx dataset and the corresponding script.
